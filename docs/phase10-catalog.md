# Phase 10: MyHome 総合機能・アプリ構成（300 項目）

ユーザーから受け取った計画（2026-10-29）の原本。300 個を全部独立アプリにするのではなく、
**独立アプリ・設定への統合・ブラウザへの統合・各種センターへの統合**に分けて整理したもの。各項目に配置先と簡単な説明が付いている。
MyHome の Swift Playgrounds 開発を想定している。

実現性（標準 API でできるか、権限・外部サービスが必要か、OS の制限で案内だけになるか）の分類は [TASKS.md](../TASKS.md) の「Phase 10」にある。

## 実装上の配置ルール

MyHome の構造は、例えば次のようにする。

```text
MyHome
├─ メインホーム画面
├─ 独立アプリ        電卓・メモ・カレンダーなど
├─ 設定              外観・管理・権限など
├─ コントロールセンター  クイック操作・通知など
├─ ブラウザ          タブ・検索・翻訳など
├─ AIセンター        生成・要約・分析など
├─ ファイル管理      PDF・ZIP・文書など
├─ 開発者ツール      コード・API・Gitなど
└─ 制作センター      画像・動画・3Dなど
```

**重要な実装上の注意**: Wi-Fi や Bluetooth のシステム設定変更、他アプリの通知取得、OS 全体の壁紙変更などは、通常の iPad アプリから自由に操作できない。
そういったものは**状態表示・設定画面への案内・MyHome 内部だけで完結する設定**として設計する。

これで 300 項目を、単純なアプリの寄せ集めではなく、ひとつの統合型ホーム環境として設計できる。
